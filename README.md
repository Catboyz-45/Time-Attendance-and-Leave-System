# Time Attendance and Leave System (ระบบบันทึกเวลาเข้างานและลาหยุด)

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการเวลาเข้า-ออกงาน (Check-in/Check-out) และการส่งคำขอลาหยุดของพนักงาน เพื่อให้การจัดการข้อมูลบุคคลภายในองค์กรเป็นไปอย่างเป็นระบบและตรวจสอบได้ง่าย

---

## 🚀 ฟีเจอร์เด่นของระบบ (Features)

* **ระบบบันทึกเวลาทำงาน (Attendance System):** บันทึกเวลาเข้างานและเลิกงานของพนักงาน
* **ระบบลาหยุด (Leave Management):** ส่งคำขอลาหยุดประเภทต่างๆ พร้อมระบุเหตุผลและวันที่ต้องการลา
* **ระบบประวัติการทำงาน (History Tracking):** แสดงตารางประวัติการเข้างานและการลาอย่างละเอียด ย้อนดูข้อมูลได้ง่าย
* **ระบบหลังบ้าน (Backend Server & Database):** มีระบบ Server และฐานข้อมูลสำหรับจัดเก็บข้อมูลอย่างปลอดภัย

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

### Front-End (ส่วนหน้าบ้าน)
* **HTML5 / CSS3:** สำหรับโครงสร้างเว็บและการตกแต่งหน้าจอให้สวยงาม รองรับการใช้งานเบื้องต้น
* **JavaScript (Vanilla JS):** ควบคุมการทำงานฝั่ง Client-side, จัดการ Event และเชื่อมต่อข้อมูลกับ API

### Back-End & Database (ส่วนหลังบ้านและฐานข้อมูล)
* **Node.js / Express:** (อยู่ในโฟลเดอร์ `server`) สำหรับสร้าง RESTful API จัดการ Request จากหน้าบ้าน
* **SQL Database:** (มีไฟล์ `history.sql`) สำหรับออกแบบโครงสร้างตารางและจัดเก็บข้อมูลประวัติ

### DevOps & Tools (การติดตั้งและจำลองสภาพแวดล้อม)
* **Docker / Docker Compose:** มีไฟล์ `docker-compose.yml` สำหรับช่วยติดตั้งและรันระบบ (Server/Database) ขึ้นมาทำงานร่วมกันได้อย่างรวดเร็ว

---

## 📂 โครงสร้างโฟลเดอร์ที่สำคัญ (Project Structure)

* `server/` — โค้ดฝั่ง Back-End API (Node.js)
* `Kanit/` — ฟอนต์ภาษาไทยที่ใช้ในระบบ
* `index.html` / `index.js` — หน้าแรกของระบบ
* `attendance.html` / `attendance.js` — หน้าบันทึกเวลาเข้า-ออกงาน
* `leave.html` / `leave.js` — หน้าส่งคำขอลาหยุด
* `history.html` / `history.js` / `history.sql` — หน้าแสดงประวัติและไฟล์โครงสร้างฐานข้อมูล
* `docker-compose.yml` — ไฟล์สำหรับรันระบบผ่าน Docker

   ```bash

3. เปิดใช้งานหน้าเว็บผ่านเบราว์เซอร์โดยเริ่มจากไฟล์ `index.html`
